# Clean India — ₹50 Lakh to Clean Bengaluru

A single-page landing site for a civic incentive pilot: teams across Bengaluru clean real public spaces in one day, waste is counted in standardised sacks, and proof is published and verifiable.

- **Prizes:** ₹10L, ₹5L, ₹2.5L for top teams, plus ₹1L each for the next 20 teams
- **Equipment fund:** ₹10L set aside so teams don't pay for basic safety/cleaning gear
- **Status:** Pilot — campaign goes live once the ₹50L goal is funded

## Why

Prompted by the state of public spaces around temple areas in Madurai, which has repeatedly topped lists of India's dirtiest cities. This is a test of whether public incentives and accountability can drive real cleanup.

## Stack

Static HTML/CSS single page (`index.html`), no build step or dependencies.

## Running locally

Open `index.html` directly in a browser, or serve the folder with any static file server:

```bash
npx serve .
```
